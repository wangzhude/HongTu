# 鸿图原生 UI 与一致性优化（2026-09-30）

本轮沿用桌面版图工作台布局，把工具操作、筛选、表单和反馈接到 ArkUI 原生组件，并统一配色、尺寸与动效。

## 组件与样式

| 区域 | 实现 |
| --- | --- |
| 标题栏、编辑和绘制工具栏 | Button，原生按压、悬停、键盘焦点、提示与无障碍名称 |
| 桌面模块导航 | Button、Badge，选中使用 primarySoft / primary |
| 通用图标 | SymbolGlyph；关闭、展开和菜单操作也使用系统符号，专业版图图标保留现有矢量资源 |
| 图层 / Cell、数据管理、验证筛选 | SegmentButton，保持父页面选中状态与控件同步 |
| 图层与数据搜索 | Search，原有过滤和搜索保存逻辑保持接通 |
| DRC 规则启用 | Checkbox，使用目标值与等值保护防止重复触发 |
| AI、Python、属性和辅助面板 | 原生按钮与输入控件，统一关闭、确认和次要操作样式 |
| 10 个编辑弹窗 | 统一输入、确认取消按钮、内边距、圆角与转场；由原生 CustomDialogController 管理模态生命周期，使用单层内容外观 |

`common/UiTokens.ets` 是尺寸来源：操作按钮 36vp、紧凑操作 32vp、表单输入 40vp、正文 13fp、说明 11fp、面板内边距 16vp、弹窗内边距 24vp、弹窗圆角 20vp。图层行、坐标与属性等密集内容保留紧凑排布。

`ThemeManager.nativeTheme()` 与 `WithTheme` 让原生控件和应用面板使用同一组语义颜色。深浅模式仍由项目现有设备与窗口逻辑选择；分段控件显式配置颜色并在主题变化时同步。API 24 的菜单文字与符号显式绑定语义颜色。

## 动效

`common/Motion.ets` 统一反馈 120ms、局部面板 220ms、辅助浮层 240ms。面板采用小距离淡入移动，浮层采用 0.98 倍淡入。根面板由页面拥有转场，避免父子重复动画。

API 23 及以上监听系统减少动态效果设置；同一个命名回调用于注册和移除，旧系统不调用该接口。动态效果减弱时自定义时长归零。结果面板高度直接更新，避免插值改变画布大小而反复刷新大版图渲染批次。
