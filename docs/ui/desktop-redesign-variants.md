## 共同约束

- 保留现有文件、绘制、编辑、图层、Cell、DRC、AI 和宏的实际回调与数据来源。
- 画布保持真实空文档状态；概念图中的图标、文字和面板内容不作为功能完成的证据。
- 手机仍使用现有紧凑布局。电脑端优先验证侧栏、工具选择、画布、检查器和窗口缩放。
- 使用本地 ArkTS 组件实现；生成图片仅作为设计参考，不铺在界面上。

## 生图提示词摘要

内置 `image_gen` 模型，`ui-mockup` 用例，以电脑模拟器现有界面截图为功能参考。三版分别要求：A 为三栏 CAD 工作台；B 为画布优先的模块竖栏和竖向工具；C 为按工作流分组的顶部功能区和底部检查器。共同要求深色高对比、中文关键标签、空画布，以及不虚构版图数据或新功能。
